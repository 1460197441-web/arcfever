# 全链路演示脚本

## 角色一：老师 / 科研工作者买家

1. 进入首页，浏览推荐仪器流。
2. 切到“分类”页，选择“海洋监测”或“地质分析”。
3. 进入仪器详情页，查看发布者、学校、认证标识、价格和设备说明。
4. 点击“立即下单”，进入订单确认页。
5. 在支付页完成模拟支付。
6. 在订单列表中查看订单状态。

## 角色二：科研工作者卖家

1. 进入“我的”，查看认证状态。
2. 在“发布”页填写仪器名称、分类、价格、城市和科研说明。
3. 发布成功后，去“我发布的”里查看并编辑仪器。

## 角色三：仪器供应方

1. 使用“发布”页新增企业仪器。
2. 在详情页中模拟买家联系卖家。
3. 在消息列表中查看会话。

## 角色四：平台管理员

1. 进入“管理后台”，查看待审核认证、在架仪器和纠纷工单。
2. 进入“学校学院管理”页面。
3. 新增学校和学院。
4. 返回认证页，用户即可选择新学校 / 新学院。

## 当前已跑通的核心链路

- 首页推荐流
- 分类筛选
- 仪器详情
- 收藏 / 加入购物车
- 下单 / 支付
- 发布仪器 / 编辑仪器
- 消息会话
- 管理员维护学校学院
