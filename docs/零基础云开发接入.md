# 神经突触：零基础云开发接入说明

## 你现在已经有的东西
- 小程序前端已经完成
- 云函数入口已经写好：`cloudfunctions/gateway`
- 数据初始化云函数已经写好：`cloudfunctions/bootstrap`
- 本地 mock 回退已经保留，云开发没配好时项目也不会直接跑崩

## 你只需要理解 3 个概念
- 云数据库：存用户、学校、仪器、认证申请这些数据
- 云函数：处理“读数据、提交认证、发布仪器、后台审核”这些逻辑
- 云存储：以后上传证明文件、仪器图片时会用到

- 首页数据

- 个人中心

- 管理后台统计
- 学校学院维护
- 认证审核列表

## 第一步：创建云开发环境
1. 打开微信开发者工具
2. 打开本项目
3. 进入“云开发”
4. 创建一个环境
5. 记下环境 ID

## 第二步：环境 ID 已经写入
当前项目已经写入：

`cloud1-7gjejudlc855f225`

对应文件：
`utils/env.js`

## 第三步：部署云函数
如果微信开发者工具 CLI 正常，可以在项目根目录执行：

```powershell
.\setup-cloud.ps1 -EnvId cloud1-7gjejudlc855f225
```

这个脚本会自动做：
- 写入 `utils/env.js`
- 安装两个云函数依赖
- 部署 `gateway` 和 `bootstrap`

## 第四步：第一次初始化数据库
在微信开发者工具里进入“云开发控制台”，手动运行一次 `bootstrap` 云函数。

它会初始化这些集合：
- `users`
- `schools`
- `instruments`
- `agreements`
- `certifications`
- `categories`
